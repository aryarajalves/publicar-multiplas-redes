Como Deixar o Token do Canal Permanente

Guia passo a passo definitivo para impedir que o Refresh Token expire a cada 7 dias e garantir automações ininterruptas no MultiPost.

⚠️

Por que o token anterior expirou em 7 dias?

No Google Cloud Console, todo aplicativo recém-criado fica por padrão com o status de publicação definido como "Em teste" (Testing). Por regra de segurança da Google, qualquer token emitido em modo de teste é automaticamente revogado após 7 dias (erro invalid_grant: Token has been expired or revoked).

✅

A Solução Definitiva: Publicar o Aplicativo

Ao mudar o status do app de "Em teste" para "Em produção" (In Production), a Google remove a expiração de 7 dias e o novo Refresh Token gerado passa a ser permanente e vitalício!

1

Alterar o Aplicativo para Modo "Produção"

  1. Acesse a tela de consentimento no Google Cloud Console:
    Abrir Tela de Consentimento OAuth ↗
  2. Certifique-se de que o seu projeto do YouTube (ex: Aryaraj - Canal Youtube) está selecionado no seletor do topo da página.
  3. Localize a seção Status de publicação (Publishing status). Você verá o status atual como Em teste.
  4. Clique no botão "Publicar aplicativo" (Publish app).
  5. Uma janela de confirmação chamada "Publicar no ambiente de produção?" será aberta. Clique em "Confirmar".
ℹ️ IMPORTANTE: Você NÃO precisa verificar o aplicativo nem gravar vídeos para a Google.
Como o aplicativo é de uso pessoal para o seu próprio canal, ele pode permanecer indefinidamente com o status de "Em produção (Não verificado)".
2

Gerar o Refresh Token Definitivo no OAuth Playground

  1. Acesse o Google OAuth 2.0 Playground.
  2. No canto superior direito, clique no ícone da Engrenagem (⚙️):
    • Marque a caixinha: ☑️ Use your own OAuth credentials.
    • No campo OAuth Client ID, cole o seu YOUTUBE_CLIENT_ID do .env.
    • No campo OAuth Client secret, cole o seu YOUTUBE_CLIENT_SECRET do .env.
    • Clique em Close para fechar a janelinha da engrenagem.
  3. Na coluna lateral esquerda (Step 1: Select & authorize APIs):
    • Role a lista até encontrar YouTube Data API v3.
    • Marque o escopo: https://www.googleapis.com/auth/youtube.upload
    • Clique no botão azul "Authorize APIs".
  4. Selecione a sua conta Google dona do canal.
  5. Se aparecer a tela amarela "O Google não verificou este app":
    • Clique em "Avançado" (Advanced) no canto inferior esquerdo.
    • Clique em "Acessar [Nome do seu App] (não seguro)".
    • Clique em "Continuar" para conceder permissão.
  6. Você retornará automaticamente ao OAuth Playground no Step 2:
    • Clique no botão azul "Exchange authorization code for tokens".
  7. Pronto! Copie o valor gerado no campo Refresh token (começa com 1//04...).
3

Salvar o Novo Token no Arquivo .env

Abra o arquivo backend/.env no servidor ou computador local e substitua a linha:

# YOUTUBE (DATA API v3 - VÍDEOS E SHORTS)
YOUTUBE_CLIENT_ID=SEU_CLIENT_ID_DO_GOOGLE.apps.googleusercontent.com
YOUTUBE_CLIENT_SECRET=SEU_CLIENT_SECRET_DO_GOOGLE
YOUTUBE_REFRESH_TOKEN=1//04_COLE_SEU_NOVO_REFRESH_TOKEN_AQUI

Depois de salvar o arquivo, reinicie os contêineres Docker para carregar o novo token:

docker restart social-publisher-api social-scheduler-worker

Dúvidas Frequentes

O token em produção pode expirar algum dia?
Apenas em duas situações: se você alterar a senha da sua conta Google ou se o sistema passar mais de 6 meses sem fazer nenhuma requisição. No uso diário do MultiPost, ele permanecerá ativo indefinidamente.
Preciso pagar alguma taxa para a Google?
Não. A YouTube Data API v3 é 100% gratuita com cota diária de 10.000 unidades por dia (suficiente para dezenas de publicações diárias).
A tela de aviso "Google não verificou este app" é um erro?
Não. É apenas um aviso padrão da Google para aplicativos criados por desenvolvedores para uso próprio. Basta clicar em "Avançado" e prosseguir normalmente.
